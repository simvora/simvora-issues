# simvora issues

This is where you tell us something on [simvora.dev](https://simvora.dev) is broken, wrong, or missing.

**[Open an issue →](https://github.com/simvora/simvora-issues/issues/new/choose)**

## What goes here

| You found… | Use |
|---|---|
| Something broken: a page won't load, the player freezes, a button does nothing | **Bug report** |
| Something wrong: a number, an explanation, a diagram or a quiz answer that isn't right | **Content error** |
| Trouble signing in, or progress that didn't save or sync | **Account & sync** |
| A system, concept or problem you'd like us to add | **Content request** |
| An idea for the site itself | **Feature request** |

**Security problems don't go here.** Please email [support@simvora.dev](mailto:support@simvora.dev). See [SECURITY.md](./SECURITY.md).

## Before you open one

1. **Search first.** Someone may have reported it already. If so, add a 👍 to the issue rather than a "+1" comment.
   We sort by reactions.
2. **One problem per issue.** Two bugs in one issue makes it hard to close either.
3. **Share the link.** Most pages on simvora.dev have a share link that opens the exact moment and state you're
   looking at. Paste it; it saves a lot of back and forth.
4. **Don't post private details.** No email addresses, tokens or screenshots of your account page. This repo is public.

## What happens next

| Label | Meaning |
|---|---|
| `needs-triage` | New, nobody has looked at it yet |
| `needs-info` | We asked you something. Issues with no reply for 14 days are closed (you can reopen) |
| `confirmed` | We can reproduce it, or agree it's wrong |
| `planned` | We intend to do it |
| `fixed-on-site` | It's live on simvora.dev |
| `wontfix` / `duplicate` / `not-a-bug` | Closed, with a reason |

Simvora is built by a small team, so we can't promise a timeline. We read everything, and we fix wrong content first.
